# 模型质量检测脚本使用说明

## 脚本位置
`scripts/model_quality_checker.py`

## 功能介绍
自动检测Maya模型的基础拓扑问题，包括：
- 多边形数量统计（顶点、边、面、三角面）
- N-gon面检测（大于4边的面）
- 重叠面检测
- 非流形边检测
- 游离顶点检测
- 自动生成优化建议

## 使用方法

### 方法一：在Maya脚本编辑器中运行
1. 打开Maya
2. 打开 窗口 → 常规编辑器 → 脚本编辑器
3. 在Python标签页中粘贴脚本内容
4. 在视图中选择要检测的模型
5. 点击执行按钮

### 方法二：通过Python命令导入运行
```python
import sys
sys.append("D:/maya-model-assistant/scripts")
from model_quality_checker import run_quality_check
run_quality_check()
```

## 检测结果说明

| 检测项 | 说明 | 严重程度 |
|--------|------|----------|
| N-gon面 | 大于4边的多边形面 | ⚠️ 中 |
| 重叠面 | 重合的多余面 | ⚠️ 高 |
| 非流形边 | 连接3个以上面的边 | ⚠️ 高 |
| 游离顶点 | 不连接任何边的孤立点 | ⚠️ 低 |
| 面数过高 | 超过10000面 | ⚠️ 视项目而定 |
